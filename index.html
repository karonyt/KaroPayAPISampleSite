KaroPay Checkout Sample

KaroCraft Market

単品購入・サブスク・決済リンクを KaroPay で受け付けるサンプルショップです。

Settings

接続設定

設定を保存してください

売上はサイト用コードの持ち主の KaroPay 口座に入ります。コードは KaroPay にログインして「受け取り」画面から取れます。詳しくは ドキュメント。

One-time

単品購入

mode: "payment"

Subscription

サブスク

mode: "subscription"

加入すると、決めた周期ごとに KaroPay が自動で請求します。解約は購入者が KaroPay の「サブスク」画面から、または受取人が管理画面から行います。

Payment Link

決済リンク

/pay/<linkId>

KaroPay の管理画面（/manage）で作った決済リンクは、そのまま共有できる固定 URL です。開くたびに新しい Checkout が作られます。サイトに置くときはリンクにするだけで、API を呼ぶ必要はありません。

History

このブラウザで作った取引

デモのため、このブラウザに記録しています。GET /api/checkout/public/sessions/:id で最新の状態を読みます。本番では自分のサーバーの DB に記録してください。

商品種類金額状態作成

まだありません

このサイトは KaroPay API のサンプルです。実際の KaroPay 口座のお金が動きます。 GitHub
