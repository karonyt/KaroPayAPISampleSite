使い方の例 / 09

決済リンクを並べるだけ

いちばん簡単な使い方です。KaroPay の管理画面（/manage）で商品と料金を作って決済リンクを発行し、その URL をボタンにします。プログラムは要りません。Discord の告知や看板の QR にもそのまま使えます。

使う API: https://karopay.karon.jp/pay/klink_...（リンクのみ） ・ このページのソース

How to

リンクの作り方

  1. KaroPay の管理画面にログインする。
  2. 「商品・料金」で商品を作り、料金（1 回払い、または毎月などの継続）を足す。
  3. 「決済リンク」で料金を選んでリンクを作り、URL をコピーする。
  4. 下の欄に貼ると、サイトに置くボタンの HTML ができます。

Builder

ボタンを作る


    

    

      
Sample
置いたときの見た目

      

        
建材セット
$800
買う

        
VIP Pass
$300 / 毎月
加入する

      

      
この見本のリンク（klink_YOUR_LINK_…）は実在しないので、押すと「リンクが無効」と出ます。

    


    

      
Points
実装のポイント

      
    
        
  • 決済リンクは何度でも使える固定の URL です。開いた人ごとに、30 分有効な新しい Checkout が作られます。
    • 
        
  • サブスクの料金で作ったリンクなら、開いた人はサブスクに加入します。
    • 
        
  • 値段を変えたいときは、管理画面で新しい料金を追加してリンクを作り直します（料金は上書きされず、前のリンクの値段は変わりません）。
    • 
        
  • 決済リンクには戻り先がありません。誰が払ったかは管理画面の「決済」「顧客」で見ます。
    • 
        
  • 決済リンクの API は KaroPay 自身の画面用で、ほかのサイトから fetch では呼べません。リンクにするだけにしてください。
